# Plan 02-05: Fraud graph hero view on the mock graph

## Goal
From a held deal, one click opens a dark graph focused on its ring: the ring is lit red, every link says what is shared and how rare it is, the clock replays it forming, and a drawer explains any edge or node, with the investigator trace as an advisory tab.

## Tasks (cut-line order)
1. Pin `react-force-graph-2d@1.29.2`. Routes `#/graph` and `#/graph/{clusterId}`; rail item "Fraud graph".
2. Pure `graphview.ts` (tested): visible edges and nodes at t, ring focus + one hop, lit ring entities (shared by 2+ ring deals and rarity >= 0.5), background deals, cluster hold time, latest hold, red-team totals.
3. Dark tokens under `:root[data-view='investigate']`; canvas colours read from CSS variables (`palette.ts`).
4. Canvas: stable layout objects (`layoutCache.ts`), deterministic seeding, gentle centre gravity, labels, weight-driven edge width, canvas halo on lit ring only, fade-in for newly visible edges, Focus ring / Whole graph fit.
5. Evidence drawer (320px): edge and node evidence, sharers, six families; Investigator tab (advisory) from `/api/investigator/{id}`; red-team chip from `/api/redteam`.
6. Audit gate: allow the dark scope and graph hold surfaces; add bans on animation and other graph libraries, `innerHTML`, rgb/hsl literals, colours near #7399C6.
7. `/api/graph` already existed in the mock (serves `fixtures/graph.json`, `?at=` filter); add `tests/test_api_graph.py` pinning the fields the view reads.

## Verify
`npm --prefix ui run test lint audit build`; `pytest -x -q tests/test_api_graph.py`; render `#/graph/C-001` against the mock API.
