  <name>Task 1: Deterministic permutation test and PMI</name>
  <files>prism/fraud/stats.py, tests/test_fraud_stats.py</files>
  <read_first>docs/MODEL_DESIGN.md (section 1: cluster p-value, PMI), prism/fraud/cluster.py (LinkSpec, PairLink rules: solo kinds, groups, weak kinds, qualify_min_groups), prism/fraud/baseline.py (deals, value_counts, deals_with, n_effective, HISTORY_COLUMN_KINDS), prism/fraud/rarity.py (FraudParams.rho)</read_first>
  <behavior>
    - `DetRng(seed: str)`: `next_u64()` from sha256(seed bytes + 8-byte counter); `randbelow(n)` by rejection sampling (unbiased); `sample(population, k)` returns k distinct items by partial Fisher-Yates over a copy. Same seed, same sequence; different seed, different sequence.
    - `history_pair_links(baseline, spec, rho) -> dict[str, dict[str, frozenset[str]]]`: for every history entity value of a non-weak kind with `2 <= df` and `df / n < rho`, every pair of its deals shares that kind; a pair qualifies when a shared kind is a solo kind or the shared kinds cover `spec.qualify_min_groups` groups. Returns adjacency of qualifying pairs only. Built once per baseline and kept on it.
    - `cluster_pvalue(members_current, members_history, links_among, baseline, spec, rho, b=1000) -> float`: `observed` = number of unordered pairs among the cluster's deals (current and history) that have a qualifying link, taken from `links_among` (a set of pairs passed in by decide: the qualifying current-to-current and current-to-history pairs from `cluster.pair_links` plus the history-to-history pairs among the cluster's history members from `history_pair_links`); `size` = total members; the null draws `b` distinct-id samples of `size` history deals with `DetRng("|".join(sorted(members)))`, counting qualifying pairs among each sample in the history adjacency; returns `(1 + count(null >= observed)) / (1 + b)`. Returns 1.0 when `size < 2` or `size` exceeds the history size.
    - `pmi_phrase(kind_a, value_a, kind_b, value_b, baseline) -> str`: `c_ab` history deals having both values, `e = df_a * df_b / n`; PMI = `log2((c_ab + 1) / (e + 1))` rounded to 1 decimal; text "<label a> and <label b> appear together in <c_ab> history deals; chance would give about <e:.2f>". No value in the text.
    - Tests on a fake history of 150 deals with a planted pair of linked history deals and many unlinked ones: the p-value for a 5-member fully linked cluster is the floor `1/1001`; for a 2-member cluster that shares nothing special (a pair that exists by chance) p is clearly above 0.05; same members give the same p twice; changing one member changes the seed; `DetRng` unbiasedness smoke test (mean of randbelow(10) over 10,000 draws within 0.2 of 4.5); the phrase for a preparer and phone that co-occur has a larger PMI than for a preparer and a bank that do not.
  </behavior>
