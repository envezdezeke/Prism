   - score_cell(cell, *, synth, run_synth, hist, cache, cfg) loops over synth.generate_cases(cell, hist, cell.count) with shift = int(cell.params.get("history_shift_days", 0)) and res = run_synth.evaluate_case_engine(case, cache.for_case(case, shift), cfg). It accumulates:
     - n_deals: number of trick deals.
     - caught: trick deals whose outcome is "hold".
     - false_flags: background deals whose outcome is "hold".
     - time-to-hold per case, when first_hold_position k is not None. With order = run_synth.arrival_order(case) and rows by deal_id, take hold time = sim_time(rows[order[k-1]]["application_date"], k) and start = sim_time of the first trick deal in order at its 1-based position. Hours = (hold - start) in hours, floored at 0.
     It returns TrickResult(name, description, n_deals, caught, catch_rate = round(caught / n_deals, 4) or 0.0 when n_deals is 0, median_time_to_hold_hours = statistics.median rounded to 1 decimal or None, false_flags).
   - run_redteam(*, chat=None, history_dir=None, cases_per_trick=4, fraud_path=None) returns a RedTeamReport.
     - hist = synth.load_history(Path(history_dir) if given else synth.history_dir_from_env()). None raises RedTeamUnavailable("history not found").
     - cfg = load_fraud_config(fraud_path), params = FraudParams.from_config(cfg), cache = run_synth.BaselineCache(hist, params).
     - In this task, cells come from the menu fallback only: the first ring strength of each family in menu order, then further strengths until there are at least 3 cells, capped at 5. Each is rebuilt with dataclasses.replace(cell, count=cases_per_trick).
     - generated_by = "deterministic trick menu (eval/trick_menu_redteam.yaml); seeded synth; engine-scored". Never include the mode or a clock in generated_by, so live and replay outputs can be byte-compared.
   - main(argv=None) uses argparse with --history-dir, --cases-per-trick (default 4), --fraud-config and --out (default client.agents_dir()/"redteam.json").
     - It writes report.model_dump(mode="json") as JSON with sort_keys, indent 2, LF and a trailing newline, and creates the parent dir.

     - It returns 0. RedTeamUnavailable or ConfigError returns 2 with the fixed message on stderr. Support python -m via an if-main guard.
