<objective>
Build the NEM-03 fraud investigator, the demo centerpiece, following the locked NEM-03 decision. It is a plain tool loop in the OpenAI chat-completions wire format on the shared ChatClient (06-01), with no agent framework. It takes at most 8 steps and uses read-only tools over the entity graph, the deals' documents and the history. For each flagged (hold) cluster it writes an evidence case for Fraud Ops with its full tool-call trace, and serves it as InvestigatorTrace on the live /api/investigator endpoint. The demo run is recorded into a committed replay cache so replay works offline. It is off the scored path and degrades to the engine's own evidence (the template case) when there are no clusters or Nemotron is off or failing.

Output: prism/agents/tools.py, prism/agents/investigator.py, prism/agents/routes.py, the app.py wiring, tests, the recorded replay cache.

   - investigate(ctx, target, chat) returns an InvestigatorTrace.
     - Messages start as [system, user "Investigate cluster ID. Current deals: ... History deals: .... Start with cluster_summary."].

     - case_summary is built by plain concatenation (no format() on document-derived text): cluster id, number of current and history deals, each fired family label with its evidence, else the deals' fraud reasons, and the closing sentence "The hold comes from the deterministic rule; this case adds no new evidence."
   - investigate_all(ctx, chat=None) returns a dict cluster_id -> InvestigatorTrace over ctx.targets[:MAX_CLUSTERS]. The default chat is ChatClient(cache_subdir="investigator"). Each trace's mode is chat.mode.
   - write_traces(traces, path, *, generated_by, mode) writes {"generated_by", "mode", "traces": {id: trace.model_dump(mode="json")}} as JSON with sort_keys, indent 2, LF and a trailing newline, and creates the parent dir.
